# Cloud90 Game Link artwork

The Cloud90 icon and game images come from the existing Cloud90 Live frontend
(`public/brand/icon-192.png` and `public/juegos/`). The images retain their
original aspect ratios and are encoded as JPEG for the native Windows client.
The app icon is generated from the existing Cloud90 icon.

Brand colors match the frontend's `src/app/globals.css`: background #0a0a0f,
surface #12121a, raised surface #1a1a26, purple #7c3aed, pink #ec4899,
cyan #06b6d4. Game art belongs to the respective rights holders.

All assets are embedded during compilation. No downloads are required at runtime.
